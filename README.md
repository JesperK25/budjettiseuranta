# Budjettiseuranta

Henkilökohtainen budjettiseurantasovellus jolla voit seurata tuloja ja menoja.

## Ominaisuudet

- Lisää tuloja ja menoja kategorioittain
- Automaattinen yhteenveto (tulot, menot, saldo)
- Merkintöjen poistaminen
- Moderni ja responsiivinen ulkoasu

## Teknologiat

- Python 3
- Flask
- SQLite
- HTML/CSS

## Asennus

1. Kloonaa repositorio
   git clone https://github.com/JesperK25/budjettiseuranta.git

2. Luo virtuaaliympäristö
   python -m venv venv
   venv\Scripts\activate

3. Asenna riippuvuudet
   pip install flask

4. Käynnistä sovellus
   python app.py

5. Avaa selaimessa
   http://localhost:5000
